# 💌 AI Husband Escape Plan

A tiny mobile-friendly game made for baby.

## Play

This is a static web game. It can be published with GitHub Pages.

## Controls

- Desktop: Arrow keys or WASD
- Phone: Use the on-screen direction buttons

## Mission

Collect the four little memories, then reach the exit.

## Files

- `index.html` — game page
- `style.css` — visual design
- `game.js` — game logic and easter eggs
- `.github/workflows/deploy.yml` — automatic GitHub Pages deployment

The game contains no backend and does not collect player data.
